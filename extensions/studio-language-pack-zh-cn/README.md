# 简体中文

AI Studio 随桌面客户端提供简体中文。首次启动即可使用，切换语言可在命令面板中运行“配置显示语言”。

核心界面与内置扩展的译文来自微软发布的 1.122.0 简体中文语言包，采用 MIT 许可证。[上游源码](https://github.com/microsoft/vscode-loc/tree/6328467f46f70a56566410dc5dcce9d6e2fec2f9/i18n/vscode-language-pack-zh-hans) · [许可证](./LICENSE.md)

`translations/studio.i18n.json` 补齐本分支的设置、菜单和工具提示。译文包括同版本其他模块中原文相同的条目、后续上游发布中对应模块和键的条目，以及本项目的中文翻译。Mermaid、Markdown 和 Git 三个扩展的词典还补充了本分支新增的设置和差异视图条目。[1.122.1 上游源码](https://github.com/microsoft/vscode-loc/tree/b835380fe5b4d3ac1461a9ea4f1b6246b8854461/i18n/vscode-language-pack-zh-hans) · [1.123.0 上游源码](https://github.com/microsoft/vscode-loc/tree/53b9e041c45ed756bb51a6f2d2eb7d56de9295b9/i18n/vscode-language-pack-zh-hans)
